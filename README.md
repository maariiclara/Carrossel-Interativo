# 🎠 Carrossel Interativo

Projeto desenvolvido com foco em praticar a criação de um carrossel interativo utilizando HTML, CSS e JavaScript.

O objetivo deste projeto foi explorar conceitos de animação, organização visual e interação do usuário em interfaces web.

---

## ✨ Funcionalidades

- Navegação lateral entre itens
- Layout visual estilizado
- Elementos promocionais
- Organização responsiva básica
- Interatividade com botões

---

## 💻 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido como prática de front-end para aprimorar conhecimentos em componentes interativos e experiência do usuário.

---

## 📚 Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Estruturação de componentes
- Manipulação visual com CSS
- Interatividade com JavaScript
- Organização de layouts
- Criação de interfaces modernas
